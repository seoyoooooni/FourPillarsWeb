# FourPillars Web

- `web`: Next.js 16, React 19, TypeScript 웹 클라이언트
- `backend`: Java 21, Spring Boot, PostgreSQL API와 서버 계산 엔진

## 로컬 실행


```bash
cd backend
JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home ./mvnw spring-boot:run
```


```bash
cd /Users/seoyoon/Desktop/FourPillarsWeb
yarn dev
yarn start
```
